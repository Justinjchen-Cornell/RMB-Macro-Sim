# VISION · 大国博弈下的财政·货币·产业一体化政策模拟器

> 定位:不是汇率模型,是**宏观政策沙盒**——以卢麒元「国家资管、弱汇强币、产业升级、
> 大国博弈」整套思想为内核,在沙盒里测试政策组合、外部冲击与博弈反应,
> 回答四个问题。

## 沙盒回答的四个问题

| 问题 | 输出 | 对应模块 |
|---|---|---|
| **节奏怎么控?** | 政策带、速度档、进二退一窗口 | policy_engine(最小政策度 k)/ outlook |
| **工具怎么选?** | 汇率×财政×进口/产业工具的分摊与成本 | trade/optimizer(四工具+约束) |
| **极端情况扛不扛得住?** | 压力测试:速冻/供给冲击/报复博弈 → 外储/红线 | capital(外储底线+报复)+ 油价推演 |
| **各地区各行业谁疼谁赚?** | 行业冲击矩阵 + 出口/进口/服务/就业分布 | model(11行业)+ industry 双口径 |

## 设计原则(记住这三条,胜过一切参数)

1. **核心价值 = 清晰呈现权衡逻辑,不是数字绝对精确**——所有输出默认给区间/带,单点只作中位参考;
2. **颗粒度 ↔ 校准成本成正比**:每加一个细分(地区/行业/渠道),必须配套可维护的参数与数据源,
   否则宁可不加(见 H5 descope 清单);
3. **机制优先于外推**:黑暗期(2024-08 后北向)、外推段一律标注"代理/外推",可降级不可假装精确。

## 边界(诚实的沙盒声明)

- 含**规范性价值判断**(卢氏三原则为内核),输出为"在该前提下的可行区间",非客观预测;
- 参数为校准假设,随数据维护;政策工具/博弈为机制近似;
- 研究框架,不构成投资建议。

## 演进路径

v1 汇率情景 → v2 政策三原则 → v3 统一引擎+双口径 → **v4 沙盒定位**(本文档)+ 结构与表达梳理
→ 后续:地区/行业颗粒度按"能校准才加"原则渐进;工具/博弈参数维护走 `params/calibration_history.log`。
