## H2 · 北向黑暗期数据源全网扫描(结论)

| 类别 | 源 | 可得性 | 说明 |
|---|---|---|---|
| 官方-交易所 | 上交所/深交所/港交所 | 日频停发(2024-08-18 起) | 全球无任何免费/付费商有**个股/日频**北向数据 |
| 官方-总量 | 港交所 connect-statistics 页面(月度) | HTML,可解析 | 总量级(成交/期末统计),需按页面结构写抓取 |
| 官方-季度 | 外管局(头寸表/外债)、央行金融报告(文本) | 人工/半自动 | 外资持 A股/债券官方总口径 |
| 国际组织 | IMF CPIS(年度,按负债国)、IMF IFS/BOP | API 免费 | 学术持仓锚,滞后 1-2 年 |
| 多边 | BIS LBS/国际证券统计 | CSV 免费 | 银行对华债权/证券 proxy |
| 商业终端 | Wind/Refinitiv/Bloomberg | 付费 | 仅总量整理,无日频个股 |
| 免费聚合 | akshare/东财/腾讯 | **已实测:均止于 2024-08-16**(腾讯 hsgt 接口已下线) | 证实监管停发,非接口问题 |

**结论与落地**:日频不存在是制度事实;采纳"官方总量半自动槽位"——`params/quarterly_foreign_holdings.csv`(股票/债券季度,人工更新)+ 港交所月度页解析脚本(后续可选)+ IMF CPIS 年度校验;校准历史每次更新入 `calibration_history.log`。

## H5 · 未建模清单(deliberately NOT modeled)

原则:**颗粒度 ↔ 校准成本成正比;能校准才加,否则如实列出**。以下均不进入引擎:

1. **结售汇/离岸微观**:银行结售汇制度、远期/期权干预、离岸 CNH 市场做市——机制近似至宏观层;
2. **地区/省际颗粒度**:行业冲击未下沉到省份/城市(需投入产出+就业面板,数据与校准成本高);
3. **完整博弈**:美国关税/金融制裁/汇率操纵标签仅以单一 us_retaliation 参数近似,无序列博弈(谈判-反制回合);
4. **预期与资产定价微观**:汇率预期形成(调查/N P F 传导)、期权隐含概率、企业避险行为;
5. **影子渠道**:贸易错报细项、地下钱庄、加密通道——以 NEE/残差笼统吸收;
6. **财政/产业内生**:财政赤字与产业政策作为工具输入,不内生政策选择过程;
7. **高频交易信号**:模型为季/月频"仓位档"信号,不产出日内/隔夜择时。

每项若未来引入,先补数据源与校准依据,再进 `params/calibration_history.log`。
