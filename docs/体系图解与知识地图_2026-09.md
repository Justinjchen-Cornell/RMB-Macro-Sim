## 0. 一句话体系

**用免费数据算两件事:①人民币升值会怎样影响经济与资产(市场情景);②怎样升才符合"消化通胀、顺差收敛、防止走资与去工业化"三原则(政策算法)——再用 Deep-Risk-OPP 的金油比/easing 做第三方互证,最后全部装进一个可交互的 dashboard。**

三层职责,别混:
- **市场层回答"会怎样"**(描述:情景模拟)
- **政策层回答"该怎样"**(规范:卢氏三原则)
- **交叉层回答"现在到哪了"**(信号:今天该信什么)

## 3. 最常绕晕的 5 个点(澄清)

1. **为什么"金人民币计价 -5%"还是推荐配置?** 模型算的是人民币计价收益;美元金仍正(央行购金+去美元化)。换汇窗口=用强势人民币换美元金,别把两个口径相加。
2. **easing 和 GOR 打架吗?** GOR 管"油和金谁便宜"(相对),easing 管"宏观帮不帮黄金"(绝对)。一个管矛,一个管盾。
3. **政策带 5-7% 是"预测"吗?** 不是。它是"给定三原则,速度落在哪段所有红线才不破"的解;现实漂移(近1年~6.2%)恰好落带内,是巧合也是政策意图的印证,不是保证。
4. **双口径去工业为什么两个数(28.8 vs 2.9)?** 一个量行业利润冲击(%),一个量 GDP 占比侵蚀(%)。都在红线35 内比较,不能跨口径比大小。缺的"换算桥系数"已列入待办。
5. **速冻(现金48%)和重估(A股+8%)矛盾吗?** 不矛盾——顺序问题:速冻先来(所有资产同跌),错杀期三档买入,重估后才有 A股+8%。现金是等错杀,不是看空。

## 4. 如何继续深化(知识地图的延伸节点)

- 想知道某行业为什么受益/受损 → 看 `real_data_report` 行业β + 行业模块公式
- 想知道政策数字怎么算 → `python policy_engine.py`(CLI 有全表)
- 想换新闻假设 → 编辑 `news_watch.yaml` → 重跑 `export_dashboard.py`
- 想验证 → `python backtest.py` / `python test_model.py`(17+3)
